# HUSLY ESTATES

Website: https://artgrandix-ltd.github.io/Uildlead-ai/

This repository is being repurposed as the website for **HUSLY ESTATES**, a London property brand.

## Current website state

- The homepage uses the HUSLY ESTATES brand and a responsive London estate-agency design.
- Visitors can filter illustrative property cards by area, sale/rent and property type.
- All properties currently shown are clearly labelled as examples. They are not live or verified listings.
- Customer enquiries are not yet connected to an inbox or database. The website therefore does not currently accept viewing requests or property instructions.
- The privacy page is a pre-launch template and must be completed before collecting personal information.

## Before opening to the public

1. Confirm the legal company/operator details and whether HUSLY ESTATES has been registered or will trade under another legal entity.
2. Add only genuine property listings for which the agency has permission, with accurate prices, tenure, descriptions, photographs and material information.
3. Connect and test a secure enquiry system, including spam protection and appropriate access controls.
4. Complete the privacy notice, cookie review, retention policy and data-sharing information.
5. Obtain the required UK estate agency, anti-money-laundering, redress, lettings and client-money advice/registrations applicable to the services actually offered.
6. Replace the example property cards with verified inventory before advertising the website as an operating agency.

Do not add secret keys, database passwords or other credentials to frontend files or this repository.
